Turn JSON into a chart

Scripts and APIs hand you JSON, not a worksheet. Paste an array of objects, or an object with labels and series, into the box on the homepage. Chartsuno reads the numbers in the browser and draws the chart. You do not upload a file, and you do not need an account to see it.

Two shapes that work

An array of objects uses one text field as the labels and every numeric field as a series. A field named month, date, label, name, or category is preferred for the labels. The other shape is an object with a labels array and a series array. Each series has a name and a data array of numbers.

[{"month":"Jan","sales":18400,"returns":900},{"month":"Feb","sales":17600,"returns":840}]
{"labels":["Jan","Feb"],"series":[{"name":"Sales","data":[18400,17600]}]}

What happens after you paste

  1. Paste into the homepage box. The same box also accepts a CSV. JSON is detected when the text starts with [ or {.
  2. Check the preview. Month names become a line chart unless you picked another type. A single numeric field is one series.
  3. Fix a value in the editor after you save. The preview is the chart. Saving, downloading a PNG, and the share link need a free account.
  4. Leave private payloads out. The paste stays in your browser until you choose Save this chart. Do not paste secrets you would not want stored with the chart.
Is it free?
You can paste data and preview a chart without an account and without paying. A free account saves up to 10 charts a month, and those saved charts can be exported as a PNG or CSV and shared with a link. Paid plans remove that monthly cap. There is no credit card for the free plan.
Do I need to sign up?
Not to paste data and see the chart. Saving to My Charts, downloading a PNG or CSV, and copying a share link need a free account. On the web, Continue with Google creates the account. The iOS app also offers Sign in with Apple.
Can I paste a JSON string from an API response?
Yes, if it is an array of objects or an object with labels and series. Nested objects that are not one of those two shapes are skipped. Chartsuno does not fetch a URL for you.
Does a .json file work, or only paste?
Both. Drop a .json file on the homepage, or paste the text. Files over 2MB are too large for the instant preview.
Will this store the raw JSON on a server before I sign in?
No. The preview is drawn on this device. The chart is sent to your account only after you sign in and save it.
