# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

People who discover, understand, save, and share charts on iPhone. Chart creators use desktop/web for advanced creation. Specific audience segments remain an open decision.

## Product Purpose

Chartsuno mobile is a social experience for charts. Every published post must connect a selected visualization, its inspectable table, and its source. An arbitrary image is not a publishable chart post.

## Operating Context

The existing iOS app bundles the React web implementation in Capacitor. The existing iPhone Pro Max is the user's review device. iOS appearance follows the system. Authentication is required before entering the mobile app.

## Capabilities and Constraints

The mobile experience prioritizes discovery and sharing; advanced chart editing belongs on web. AI may assist image-to-table extraction, but whether and how to expose that is being researched. Existing stored charts contain data, configuration, and multiple legacy source fields. Published revisions and the new mobile composer are planned, not existing capabilities.

Author-collected data may be published with an explicit “My own data” disclosure, a collection description, and a public display table. An external source URL is optional for this source kind. This is attribution, not independent verification, and does not permit image-only publication. Confirmed by the user on 2026-11-10.

## Brand Commitments

Preserve the Chartsuno identity and existing system-based iOS appearance. “Instagram for charts” describes the social browsing experience, not image-only uploads or copying another product's branding.

## Evidence on Hand

Existing app, API models, chart/table renderers, and authenticated Pro Max session. Research and implementation sequencing: ../../docs/product/mobile-data-backed-posts.md. No claims of verified data or universal provenance coverage are supported by the current implementation.

## Product Principles

- Every post is understandable as a visualization, table, and source declaration.
- Public display data is separate from private uploads and editor metadata.
- Provenance and user review are not proof that a claim is true.
- Mobile publishing stays focused; advanced analytical work stays on web.
