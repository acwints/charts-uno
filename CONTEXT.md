# Chartsuno Context

## Domain Terms

### Chart Workbench

The chart editing surface that combines the document toolbar, chart/data view switcher, preview column, data editor, and inspector controls for a single chart draft or saved chart.

### Inspector

The right-side control surface for chart title, source, branding, chart logic, data summary, dual-axis settings, and styling.

### Preview

The rendered chart or table that users inspect, export, and share.

### Model Configuration

The single place that resolves AI model names for chart generation, research, SQL drafting, stock insight, and vision extraction. It keeps production defaults stable while allowing experiments through environment variables.

### Chart Generation Eval

The repeatable fixture set used to check that prompt-based chart generation returns valid labels, series, data lengths, and chart-type choices before newer model experiments are promoted.
