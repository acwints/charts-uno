# Ad 1: The Transformation

**Angle:** Before/after — show the gap between default charts and Chartsuno output

## Tweet Copy

```
Your charts are losing you credibility.

Default Excel charts say "I spent 5 minutes on this."

Chartsuno charts say "I know what I'm talking about."

Same data. Completely different impression.

Try it free: chartsuno.com
```

## Image Concept

**Format:** Side-by-side split image (left: "Before" / right: "After")

- **Left side:** A generic, flat Excel-style bar chart with gray gridlines, default blue bars, Arial font, no title styling — the kind of chart everyone has seen in a boring slide deck. Slight desaturation. Label: "BEFORE"
- **Right side:** The same data rendered through Chartsuno — editorial style variant, gradient bars (blue-to-cyan), Instrument Serif title, clean axis labels, rounded corners, subtle shadow. Label: "AFTER"
- **Bottom strip:** Chartsuno logo + "chartsuno.com" in small text

**Screenshot method:** Render a bar chart in ChartPreview with `styleVariant: 'editorial'`, `colorScheme: 'default'`, `themeMode: 'dark'` for the "after" side. For the "before" side, create a plain Chart.js bar chart with default settings.
