# Twitter Ad Campaign — Chartsuno Launch

3 ads targeting different segments and angles. Post as organic tweets with images.

## Ad Schedule

| Ad | Angle | Best Time | Target Audience |
|----|-------|-----------|-----------------|
| 1. Transformation | Before/after visual | Tue/Thu 9am ET | Designers, PMs, anyone who presents data |
| 2. Screenshot Magic | Wow-factor feature | Mon/Wed 12pm ET | Data analysts, researchers, students |
| 3. Paste and Go | Speed + simplicity | Sun/Fri 7pm ET | Startup founders, VCs, deck builders |

## Image Generation

Each ad file includes a **Screenshot method** section with exact Chartsuno config values to render the visuals. Use the marketing server's browser-capture pipeline or manually screenshot the app.

## Engagement Strategy

- Reply to all comments within 1 hour
- Quote-tweet with "thread" follow-ups showing more chart styles
- Pin the best-performing ad to profile
- Cross-post to LinkedIn with slightly longer copy (add a "here's how it works" paragraph)
