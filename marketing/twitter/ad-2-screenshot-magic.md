# Ad 2: Screenshot Magic

**Angle:** The "screenshot to chart" feature — the wow factor of uploading a photo and getting a beautiful chart back

## Tweet Copy

```
I took a screenshot of an ugly chart from a PDF report.

Dropped it into Chartsuno.

10 seconds later: AI extracted the data and rebuilt it as a beautiful, editable chart.

This should not be free.

chartsuno.com
```

## Image Concept

**Format:** 3-panel horizontal strip showing the workflow

- **Panel 1:** A phone screenshot of a low-quality chart from a PDF — pixelated, small, embedded in a dense report page. Arrow pointing right.
- **Panel 2:** The Chartsuno upload interface showing the image being processed — "AI is analyzing your image..." with the processing indicator.
- **Panel 3:** The finished result — a clean, professional area chart with the same data, styled in the "minimalist" variant with cool colors.
- **Bottom:** "Screenshot. Drop. Done." tagline + Chartsuno logo

**Screenshot method:** Use the image upload flow in ChartBuilder. Capture each step: (1) a sample chart screenshot, (2) the AIProcessingIndicator overlay, (3) the final ChartPreview output.
